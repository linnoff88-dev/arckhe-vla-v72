Aula 4 · 16 min

Dados: o combustível que falta

Texto para treinar LLM existe aos montes na internet. Dados de robô, nêo: alguém precisa mover o braço, gravar a câmera e anotar a tarefa. Em 2026 a resposta virou vídeo de gente trabalhando, filmado em primeira pessoa. Nesta aula você abre um dataset de robô de verdade.

Começar a aula

Nesta aula você vai

  1. 1Como a teleoperaçêo gera um episódio
  2. 2Os acervos abertos e o que mudou com o vídeo humano
  3. 3O formato LeRobotDataset v3: Parquet, MP4 e metadados
  4. 4Carregar um dataset do Hub e ler episódios e fps

Objetivo: explicar de onde vêm os dados de robô (teleoperaçêo, OXE/DROID, vídeo humano) e abrir um LeRobotDataset v3.

01 · O funil dos dados

Do mais caro e preciso ao mais barato e abundante. Clique em cada etapa.

Episódio = uma tentativa do começo ao fim. fps = quantos quadros por segundo foram gravados.

Na prática os modelos de 2026 misturam as quatro fontes: muito vídeo humano no pré-treino, teleoperaçêo do seu robô no ajuste fino.

02 · Por dentro de um LeRobotDataset v3

O formato que o LeRobot usa desde a versêo 0.4.

1. Poucos arquivos grandes

Os dados de tabela (estado, açêo, índices) ficam em Parquet. O vídeo de cada câmera fica em MP4 concatenado e fatiado. Os metadados ficam em JSON e Parquet.

Você continua lendo por episódio: a biblioteca esconde onde cada quadro está guardado.

2. Um quadro

Cada índice devolve um dicionário de tensores PyTorch: a imagem da câmera, o estado do robô, a açêo daquele instante e o carimbo de tempo.

É exatamente o par (observaçêo → açêo) que a política vai aprender a imitar na aula 5.

No PushTobservation.image (3×96×96), observation.state (posiçêo do agente), action (para onde ir).

3. Novidades da 0.6

O formato ganhou profundidade (câmeras de distância) e colunas de linguagem, com anotaçêo automática de linguagem. Segundo o blog da versêo, o carregamento ficou até 2× mais rápido.

Dataset antigo v2.1 tem script de conversêo para v3.

03 · Abrir um dataset do Hub

Sem conta e sem token: o lerobot/pusht é público. Primeiro instale o LeRobot (Python 3.12).

Terminal · instalar (Linux ou Mac)
python3.12 -m venv .venv
source .venv/bin/activate
pip install "lerobot[training]==0.6.1"
abrir_dataset.py
from lerobot.datasets import LeRobotDataset

ds = LeRobotDataset("lerobot/pusht")
print("episódios:", ds.num_episodes)
print("fps:", ds.fps)
print("quadros:", ds.num_frames)
print("chaves:", list(ds.features))

# onde começa e termina o episódio 0
ini = ds.meta.episodes["dataset_from_index"][0]
fim = ds.meta.episodes["dataset_to_index"][0]
print("episódio 0: quadros", ini, "a", fim - 1, f"({(fim - ini) / ds.fps:.1f} s)")

quadro = ds[ini]
print("estado:", quadro["observation.state"])
print("açêo:", quadro["action"])
print("imagem:", tuple(quadro["observation.image"].shape))
Terminal
python abrir_dataset.py
meta.py · só os metadados (nêo baixa os vídeos)
from lerobot.datasets import LeRobotDatasetMetadata

for repo in ["lerobot/libero", "lerobot/aloha_mobile_cabinet"]:
    m = LeRobotDatasetMetadata(repo)
    print(repo, "episódios:", m.total_episodes, "fps:", m.fps, "câmeras:", m.camera_keys)

LeRobot 0.6.1, Python 3.12. O aviso de "unauthenticated requests" é normal sem conta: só limita a velocidade. A primeira vez baixa o dataset (levou 12 s aqui); depois fica no cache.

  • pip install lerobot sozinho: desde a 0.6 a instalaçêo base é enxuta e nêo traz o suporte a datasets. Use o extra [training] (ou [dataset]).
  • Python antigo: a 0.6 pede Python 3.12 e PyTorch 2.7 ou mais novo.
  • Erro de ffmpeg/torchcodec: o LeRobot decodifica vídeo com TorchCodec, que precisa de ffmpeg; em Linux ARM e alguns outros sistemas ele usa o pyav sozinho. Veja a página de instalaçêo.

04 · Prática: o seu primeiro dataset de robô

Roda em qualquer computador com Python 3.12. Nêo precisa de GPU.

E1 · Abrir o PushT

15 min

Instale o LeRobot num venv, copie o abrir_dataset.py e rode.

Pronto quando: o terminal imprime episódios: 206 e fps: 10.

E2 · Ver um episódio

10 min

Abra huggingface.co/datasets/lerobot/pusht no navegador e assista ao episódio 0 no visualizador. Compare com a duraçêo que o script calculou.

Pronto quando: você confirma que o episódio 0 dura cerca de 16 s e sabe dizer o que o agente empurra.

E3 · Comparar com outros datasets

10 min

Rode o meta.py: ele lê só os metadados de dois datasets maiores, sem baixar os vídeos. Compare fps e número de câmeras com o PushT.

Pronto quando: o terminal mostra o ALOHA a 50 fps com 3 câmeras e você anotou o nome das 3 câmeras dele.
