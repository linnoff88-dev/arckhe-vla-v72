Lesson 4 · 16 min

Data: the missing fuel

Text for training an LLM is everywhere on the internet. Robot data isn't: someone has to move the arm, record the camera, and label the task. In 2026 the answer became video of people working, filmed in first person. In this lesson you open a real robot dataset.

Start the lesson

In this lesson you will

  2. 2The open collections and what changed with human video
  3. 3The LeRobotDataset v3 format: Parquet, MP4, and metadata
  4. 4Load a dataset from the Hub and read episodes and fps

Goal: explain where robot data comes from (teleoperation, OXE/DROID, human video) and open a LeRobotDataset v3.

01 · The data funnel

From the most expensive and precise to the cheapest and most abundant. Click each stage.

Episode = one attempt from start to finish. fps = how many frames per second were recorded.

In practice, 2026 models mix all four sources: lots of human video in pretraining, teleoperation of your own robot in fine-tuning.

02 · Inside a LeRobotDataset v3

The format LeRobot has used since version 0.4.

1. A few large files

Tabular data (state, action, indices) lives in Parquet. Each camera's video lives in concatenated, sliced MP4 files. Metadata lives in JSON and Parquet.

You still read by episode: the library hides where each frame is stored.

2. One frame

Each index returns a dictionary of PyTorch tensors: the camera image, the robot state, the action at that moment, and the timestamp.

It's exactly the (observation → action) pair that the policy will learn to imitate in lesson 5.

In PushTobservation.image (3×96×96), observation.state (agent position), action (where to go).

3. What's new in 0.6

The format gained depth (distance cameras) and language columns, with automatic language annotation. According to the release blog, loading got up to 2× faster.

An old v2.1 dataset has a conversion script to v3.

03 · Open a dataset from the Hub

No account and no token: lerobot/pusht is public. First install LeRobot (Python 3.12).

Terminal · install (Linux or Mac)
python3.12 -m venv .venv
source .venv/bin/activate
pip install "lerobot[training]==0.6.1"
abrir_dataset.py
from lerobot.datasets import LeRobotDataset

ds = LeRobotDataset("lerobot/pusht")
print("episodes:", ds.num_episodes)
print("fps:", ds.fps)
print("frames:", ds.num_frames)
print("keys:", list(ds.features))

# where episode 0 starts and ends
ini = ds.meta.episodes["dataset_from_index"][0]
fim = ds.meta.episodes["dataset_to_index"][0]
print("episode 0: frames", ini, "to", fim - 1, f"({(fim - ini) / ds.fps:.1f} s)")

quadro = ds[ini]
print("state:", quadro["observation.state"])
print("action:", quadro["action"])
print("image:", tuple(quadro["observation.image"].shape))
Terminal
python abrir_dataset.py
meta.py · metadata only (doesn't download the videos)
from lerobot.datasets import LeRobotDatasetMetadata

for repo in ["lerobot/libero", "lerobot/aloha_mobile_cabinet"]:
    m = LeRobotDatasetMetadata(repo)
    print(repo, "episodes:", m.total_episodes, "fps:", m.fps, "cameras:", m.camera_keys)

LeRobot 0.6.1, Python 3.12. The "unauthenticated requests" warning is normal without an account: it only limits speed. The first time it downloads the dataset (took 12 s here); after that it stays in the cache.

  • pip install lerobot on its own: since 0.6 the base install is lean and does not include dataset support. Use the [training] extra (or [dataset]).
  • Old Python: 0.6 requires Python 3.12 and PyTorch 2.7 or newer.
  • ffmpeg/torchcodec error: LeRobot decodes video with TorchCodec, which needs ffmpeg; on Linux ARM and some other systems it falls back to pyav on its own. See the installation page.

04 · Practice: your first robot dataset

Runs on any computer with Python 3.12. No GPU needed.

E1 · Open PushT

15 min

Install LeRobot in a venv, copy abrir_dataset.py, and run it.

Done when: the terminal prints episódios: 206 and fps: 10.

E2 · Watch an episode

10 min

Open huggingface.co/datasets/lerobot/pusht in your browser and watch episode 0 in the viewer. Compare it with the duration the script calculated.

Done when: you confirm that episode 0 lasts about 16 s and you can say what the agent is pushing.

E3 · Compare with other datasets

10 min

Run meta.py: it reads only the metadata of two larger datasets, without downloading the videos. Compare fps and number of cameras with PushT.

Done when: the terminal shows ALOHA at 50 fps with 3 cameras, and you noted the names of its 3 cameras.
