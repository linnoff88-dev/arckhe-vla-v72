Lesson 3 · 16 min

The model map in 2026

There are dozens of VLAs, and the best one on the chart may be the one you can't use. Before size and benchmark scores, three questions decide: are the weights downloadable, does the license allow your use case, and is access free, paid, or partners only.

Start the lesson

In this lesson you will

  1. 1Which models are open and which are closed as of Oct 2026
  2. 2The five ways to get access: Apache, custom license, non-commercial, API, and early access
  3. 3Where to find the license, size, and robots on a model card
  4. 4Why LIBERO no longer works for choosing a model

Goal: choose a model for a real use case by license, size, and access (open, non-commercial, API, early access).

01 · Open × closed

Click each group. The order goes from most free to most restricted.

On Hugging Face, the license sits at the top of the model card (the license field). Gated means you have to request access.

Open doesn't mean free: read the weights' license, which can differ from the code's license.

02 · How to choose in four questions

Click each step and answer for your own case.

1. Can I download it?

If the model only exists through an API or for partners, you depend on another company for every test.

Watch out for gated access: GR00T N1.7 downloads on its own, but it loads the nvidia/Cosmos-Reason2-2B backbone, which is gated. If you don't request access on the Hub, the run fails with GatedRepoError, according to the Isaac-GR00T README.

2. Can I use it in my case?

Study and research: almost anything that is open works, including G0.5.

Product or client: Apache-2.0 or a license that allows commercial use, read to the end.

CaseAn integrator wants to put an arm on a packaging line: G0.5 is out because of its license; GR00T N1.7 or π0.5 make the list.

3. Does it fit my hardware?

SmolVLA has 450M parameters and was built for consumer hardware. GR00T N1.7 has 3B and was built to run on NVIDIA GPUs (check the model card for which ones). DreamZero has 14B.

The LeRobot 0.6 hardware guide measures video memory per policy family: check it before you buy.

4. Does it work on my robot?

Check which robots the model was validated on. N1.7 was validated on Unitree G1, YAM, and AGIBot Genie 1; SmolVLA, on the SO-100/101.

Don't choose by LIBERO: in 2026 several models pass 97% (X-VLA 98.1%; MolmoAct 2-Think 98.1%). Look at RoboArena, MolmoBot, RoboTwin 2.0, or third-party evaluation.

Example from the repository
  • lerobot/smolvla_base: license apache-2.0; base HuggingFaceTB/SmolVLM2-500M-Video-Instruct; not gated; fine-tune with lerobot-train --policy.path=lerobot/smolvla_base.
  • nvidia/GR00T-N1.7-3B: weights under the NVIDIA Open Model License Agreement; code on GitHub under Apache 2.0; 3,000,000,000 parameters; training data "Hybrid: Human, Robot, Simulated", 13 datasets; the Cosmos-Reason2-2B backbone is gated.
  • Copying the code license: in GR00T the code is Apache 2.0, but the weights are not.
  • Assuming open = commercial: G0.5 is open and non-commercial.
  • Taking the parameter count from an aggregator: use the card or the paper; the "5.4B" for MolmoAct 2, for example, only shows up on aggregators.
